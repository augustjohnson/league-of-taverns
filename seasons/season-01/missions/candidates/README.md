# missions/candidates

LLM-drafted (or hand-written) candidate missions, structure only. Each one must
pass `scripts/validate`. The GM picks ~6 using the difficulty report and
moves them to `../selected/`.

Candidates reveal the selected missions, so they need the same secrecy
(docs/decisions.md D-18). `example-drowned-toll.yaml` is a hand-written shape
example and is not secret.
